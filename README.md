# Reacter

Reacter is a full-stack social media platform where users can create posts, like content, comment, follow other users, and chat in real time.

## Features

- User authentication
- Create and manage posts
- Like and comment
- Follow users
- Real-time messaging
- Notifications

## Tech Stack

### Frontend
- React
- TypeScript

### Backend
- Node.js
- Express

### Database
- MongoDB

## Purpose

Reacter was built to explore scalable full-stack architecture and modern web development practices.
